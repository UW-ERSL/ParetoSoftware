To compile Pareto with CUDA

1. Make sure you have a recent GPU card (2016+ release)

2. Download and install CUDA 10, from https://developer.nvidia.com/cuda-10.0-download-archive
It will be assumed that it is installed in "C:/Program Files/NVIDIA GPU Computing Toolkit/CUDA/v10.0"
(If not, you have to change the two .pri files below)

3. Add the following lines to paretoCore.pro at the very beginning
# to compile cuda code,
# 1. uncomment the line #define COMPILE_GPUCODE in CommonDefines.h
# 2. uncomment line below
# 3. uncomment the line include(./cudaParetoWinInclude.pri) in paretoTopOpt.pro
include(./cudaParetoCoreInclude.pri)

4. Place the file cudaParetoCoreInclude.pri in ParetoCore directory

5. Uncomment the line "#define COMPILE_GPUCODE" in CommonDefines.h

6. Compile ParetoCore

7. Add the following lines to paretoCore.pro at the very beginning
# to use cuda code, uncomment below
include(./cudaParetoWinInclude.pri)

8. Place the file cudaParetoWinInclude.pri in ParetoWin directory

9. Compile ParetoTopOpt

--- 
To compile without cuda
1. Comment include(./cudaParetoCoreInclude.pri)
2. Comment #define COMPILE_GPUCODE
2. Comment include(./cudaParetoWinInclude.pri)
