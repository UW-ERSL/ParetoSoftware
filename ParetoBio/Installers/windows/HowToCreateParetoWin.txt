
Steps to create ParetoWinInstaller


1. in LiveVariables.hpp turn various options at the top of the file to false

2. Change VERSION and BUILDDATE of ParetoCore in CommonDefines.h

3. Change PARETO_TEMP_EXPIRY in MacAddresses.txt

4. Compile ParetoWin 

5. Run cleanup.bat in ParetoExamples

6. If there are changes to the ppt guide, make a new pdf and place it in resources directory

7. Use ParetoWinInno64Bit to create ParetoWinInstaller

8. Open ParetoWinCertificate  (you will need Ksign from http://codesigning.ksoftware.net/)

9. Sign the installer 

10. Use the installer to test all examples in ParetoGuide

11. The installer and ParetoGuide.pdf are ready for distribution
